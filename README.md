# Kyara

Kyara is a custom language i built as my graduate project, language is built with **C++** and powered by the **LLVM compiler infrastructure**.  
This project is a personal exploration into language design, compiler construction, and systems programming.

---

## ✨ Features
- **Custom Syntax**: Designed to be simple yet expressive.
- **LLVM Backend**: Leverages LLVM for code generation and optimization.
- **C++ Implementation**: Written in modern C++ for performance and flexibility.
- **Extensible Design**: Built with modularity in mind, making it easier to add new features.

- ## 🚀 Getting Started

### Prerequisites
- **C++17 or later** (tested with GCC/Clang/MSVC)
- **LLVM** (version 14+ recommended)
- **CMake** (for build configuration)
